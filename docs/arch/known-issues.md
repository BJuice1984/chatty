# Известные особенности и технический долг

Обратный список находок из архитектурного анализа — кандидаты на исправление. Порядок — по убыванию пользы от исправления. Отмечайте сделанное галочкой.

- [ ] **1. Каждый `setProps` перерисовывает блок целиком**
  - Где: `src/helpers/isEqual.ts`, `src/core/Block.ts` (`componentDidUpdate`)
  - Что: `isEqual` — строгое `===`, а не глубокое сравнение; при этом `componentDidUpdate` игнорирует его результат и всегда возвращает `true`. Любая запись в пропсы → полный ре-рендер (включая детей).
  - Направление: сделать `isEqual` глубоким сравнением объектов и вернуть его результат из `componentDidUpdate`. Заодно это предусловие для пункта 2.

- [ ] **2. `withStore` перерисовывает подписчика при любом обновлении Store**
  - Где: `src/utils/Store.ts` (HOC `withStore`)
  - Что: селектор `mapStateToProps` вычисляется и уходит в `setProps` на каждое `StoreEvents.Updated`, даже если срез состояния компонента не изменился.
  - Направление: сравнивать прошлый и новый результат селектора (потребуется рабочий `isEqual` из п. 1) и звать `setProps` только при изменении.

- [ ] **3. Роутер молчит на неизвестном пути**
  - Где: `src/utils/Router.ts` (`getRoute` / `_onRoute`)
  - Что: для незарегистрированного пути `_onRoute` тихо выходит — экран остаётся прежним; страница `/404` доступна только по прямой ссылке.
  - Направление: fallback на маршрут 404, когда `getRoute` вернул `undefined`.

- [x] **4. `commitlint` не подключён к коммитам** — закрыто 2026-09-27 в PR #13: commit-msg хук подключён, конфиг переименован в `commitlint.config.cjs`.

- [ ] **5. `fetchWithRetry` — мёртвый код**
  - Где: `src/helpers/fetchWithRetry.ts`
  - Что: не импортируется нигде; `HTTPTransport` целиком на XHR и без retry.
  - Направление: либо удалить, либо перенести retry-логику в `HTTPTransport.request` (повтор при сетевой ошибке/5xx).

- [ ] **6. Билд-ворнинг: SVG не резолвится**
  - Где: сборка `vite build` (сообщение `…images/delete-svgrepo-com.svg didn't resolve at build time`)
  - Что: ссылка на картинку в каком-то из шаблонов/стилей остаётся неразрешённой и отдается как есть — на проде путь может отдать 404.
  - Направление: найти источник ссылки (`grep -rn "delete-svgrepo-com" src/`) и поправить путь или импортировать ассет.

- [ ] **7. Опечатка в имени плагина**
  - Где: `vite-plugin-handelbars-precompile.ts` (и импорт в `vite.config.ts`)
  - Что: «handelbars» вместо «handlebars» в имени файла.
  - Направление: переименовать файл и обновить импорт. Чисто косметика, но путает при поиске.
