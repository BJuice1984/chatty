## Известные ограничения продукта (зафиксированы осознанно)

- Перерисовка ленты O(n) на каждое обновление без виртуализации — non-goal
  (review N-2 прогона bot-wait-offline); на текущих длинах ленты приемлемо.
- Стриминг ответа бота видит только вкладка, задавшая вопрос (у других
  нет pending-хвоста — им приходит финальное сообщение). Возможный
  follow-up — run-scoped плейсхолдеры.
- Полный redraw без virtual DOM: символы, напечатанные в окно замены DOM
  (~кадр после перерисовки), могут теряться; между перерисовками фокус и
  черновик стабильны (слоты `composer-state`). Кандидат на будущее —
  keydown-redirect при `activeElement === body`.
- Привязка «человек графика → аккаунт» в отпускном скилле не проверяется:
  любой аккаунт может подтвердить любую фамилию из графика (п.5 backlog
  NEXT.md, отложено оператором до дизайн-проекта регистрации).
