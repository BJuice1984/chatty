# Decisions — 2026-11-07-messenger-ux-pack-2 (журнал операторских замещений)

Оператор делегировал разрешение блокеров контроллеру прогона (сообщение
сессии 2026-11-07: «блокеры реши сам с учётом проекта, но запиши, что
решол»). Каждый пункт: ситуация → решение → чем проверено.

## D-1. Какую иконку «вернуть» (item 1)

- Ситуация: заявка «была заменена иконка прочитанных, посмотри в main
  старую и верни». Факты git: фича mark-all-read ПРИШЛА сразу с файлом
  mark-all-read-icon.svg (f6e839d); единственное изменение графики —
  цвет stroke currentColor→#F7F7FC (6b690b0, фикс почернения на тёмной
  шапке); в main фичи нет — на второй позиции шапки стоит
  settings-icon.svg (шестерёнка).
- Решение: выполнить буквально указание «в main»: ВТОРАЯ иконка шапки
  возвращает ВИЗУАЛ settings-icon.svg, ФИЧА остаётся как есть (клик —
  markAllRead, гейтинг hasUnread, disabled-пропс). alt оставлен
  описывающим действие фичи («Иконка. Пометить всё прочитанными») —
  юзер просил заменить иконку, не доступность.
- Откат-подсказка: если имелась в виду ранняя ЧЁРНАЯ версия галки —
  однострочный откат stroke в самом svg (6b690b0^).

## D-2. Один воркстрим вместо трёх

- Ситуация: пункты пака массово пересекаются по файлам (chat.ts/hbs,
  chat.scss, messenger.scss, controller.ts нужны 2–3 пунктам
  одновременно) — три воркстрима нарушали бы disjoint-правило
  write-сетов.
- Решение: ОДИН фронтовый воркстрим-владелец WS-ALL (прецедент
  2026-11-04-bot-wait-offline: «the whole frontend beyond core in ONE
  owner»), исполнение одним треком; тир остаётся S2 по browser-risk.

## D-3. Формулировка «плашка по аналогии» (item 6)

- Решение: «Чат недоступен» — error-бабл (isError, жёлтая семья
  _error), НЕ service-line: юзер в качестве образца приложил именно
  бабл «⚠ Ассистент недоступен». Текст «⚠ Чат недоступен».

## D-4. Галочка «когда сообщение ушло» (item 10)

- Решение: сегодня между отправкой и эхом НЕТ ничего — добавляем
  оптимистичную запись с маркером «отправляется» и, после эха (серверный
  id), одиночную «✓» у своих сообщений. Галочка = «принято сервером»,
  не «прочитано» (read-receipts вне паки). Замена временной записи —
  FIFO по oldest-temp (стабилен для повторов одинакового текста).

## D-5. «Светлый стандартный» текст чипа авто-названия (item 8)

- Решение: --second-text-color (#ADB5BD): в чипе сегодня указан
  НЕсуществующий --secondary-text-color (текст без собственного цвета);
  main-text-color (#F7F7FC) был бы белым — «стандартным светлым» в
  репо считается second (так красятся хинты и сниппеты).

## D-6. Подложка карандаша (item 3) — целевая область

- Решение: подложка добавляется только аватару_смены
  (_type_change-profile, 150px) — именно там карандаш просвечивает под
  svg; главная строка профиля по item 5 вообще теряет hover. Обе правки
  скоуплены в chat.scss без изменения логики UserAvatar.

## D-7. Live-disabled форм без перерисовки (item 4)

- Решение: императивное переключение атрибута disabled по input-событию
  (без setProps/ререндера) — рендер-путь (по образцу register.ts)
  пересоздавал бы инпуты на каждом нажатии и ронял фокус; черновики
  фронт-форм и так держатся на DOM-значениях. Риски покрыты тестами
  обеих форм.

## D-8. Бюджеты/расписание

- Решение: воркстрим wall 7200s, попытки 3; фронтовые гейты после
  каждой логической пачки (не после каждого пункта) — verify ~90с,
  полный прогон после всех правок.
